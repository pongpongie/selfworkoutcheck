# 심트 · Simple Training

주 4일 상하체 2분할 + 자유 요일 운동 기록 PWA.
정적 파일 몇 개와 서비스워커가 전부다. 빌드 도구도 의존성도 없다.

```bash
python3 -m http.server 8080   # http://localhost:8080
node test.js                  # 단위 테스트 (의존성 0)
```

---

## 화면 구조

하단 탭 3개 + 헤더 설정. 요일 선택은 「운동」 안의 2차 내비게이션이다.

```
심트                        08/10  [⚙]     ← 설정은 헤더 아이콘
[D01][D02][D03][D04][엑스트라]              ← 운동 구획에서만 표시
                                            
 (본문)
                                            
   [운동]        [기록]        [통계]        ← 엄지가 닿는 곳
```

| 구획 | 하는 일 |
|---|---|
| **운동** | 요일별 종목 카드에 세트를 입력. 기록할 날짜를 바꿀 수 있다 |
| **기록** | 월 캘린더. 날짜를 누르면 그날 한 종목·세트·볼륨 |
| **통계** | 종목별 최고 세트 중량 추이 그래프 |
| **설정** | 테마, 캐시 비우기, 저장 공간, 데이터 백업 |

헬스장에서 한 손으로 쓰는 앱이라 주 내비게이션을 하단에 뒀다.
설정처럼 어쩌다 쓰는 것은 헤더로 빼서 매일 쓰는 메뉴와 비중을 나눴다.

## 기능

| 기능 | 설명 |
|---|---|
| 운동 기록 | 종목을 탭하면 세트별 중량·반복수 입력창이 열린다. **입력 즉시 저장** |
| 지난주 비교 | 카드에 직전 세션 기록 표시. "지난 기록 불러오기"로 그대로 채우기 |
| 휴식 타이머 | ✓ 누르면 종목별 휴식 시간으로 자동 시작. 종료 시 비프 + 진동 |
| 날짜 바꾸기 | 지난 날짜로 돌려 적기. 앞날은 막는다 |
| 캘린더 | 운동한 날을 볼륨 농도로 표시. 날짜별 상세 |
| 중량 추이 | 종목별 최고 세트 중량 그래프 |
| 종목 검색 | 8부위 144종목. 이름·초성·영문으로 검색 |
| 엑스트라 | 정해진 종목이 없는 자유 요일 |
| 다크/라이트 | 시스템 · 라이트 · 다크 3분기 |
| 원판 계산 | 바벨 종목은 봉 20kg 기준 한쪽 원판 구성 자동 표시 |
| 오프라인 | 한 번 열면 신호 없어도 실행 |
| 백업 | JSON 내보내기 · 불러오기 · 전체 삭제 |
| 키보드 | Tab 이동, Enter/Space 로 카드 펼치기 |

## 파일

```
index.html      UI · 이벤트 (인라인 스타일 + 스크립트)
tokens.css      디자인 토큰 (라이트/다크)
core.js         순수 로직 — 원판 계산, 기록 조회, 검색, 캘린더, 백업 검증
exercises.js    부위별 종목 카탈로그 (데이터만)
test.js         core.js · exercises.js 단위 테스트
sw.js           서비스워커 (오프라인 캐시)
manifest.json   PWA 매니페스트
icon-*.png      아이콘 3종
make-icons.py   아이콘 생성기 (표준 라이브러리만 사용)
```

`core.js` 는 DOM 도 localStorage 도 건드리지 않는다.
브라우저에서는 `window.Gym`, node 에서는 `module.exports` 로 노출돼서
같은 코드를 그대로 테스트한다.

## 디자인 시스템

[DesignCode UI](https://designcode.io) 킷의 토큰을 `tokens.css` 에 옮겼다.
색·타이포·간격을 여기서만 관리하므로, 테마를 바꾸려면 이 파일만 손대면 된다.

| 항목 | 값 |
|---|---|
| 폰트 | Inter (UI) · Roboto Mono (숫자) |
| 타이포 | 헤딩 40/30/28/24 · headline 20 · body 16 · footnote 14 · caption 13 · small 12 |
| 뉴트럴 | `--n0` ~ `--n900` 19단계 |
| 액센트 | iOS 시스템 팔레트 — blue `#007aff`, green `#34c759`, red `#e8362c` … |
| 콘텐츠 색 | 흑/백 알파 **100 / 70 / 50%** — 라이트·다크가 같은 규칙 |
| 간격 | 6 / 16 / 20 / 24 / 32 · 컨테이너 radius 10 · 버튼 radius 8 |
| 터치 타깃 | 44px |

### 아이콘

`make-icons.py` 로 만든다. 의존성 없이 순수 파이썬이 그라디언트·마크·알파를
계산하고 PNG 를 직접 인코딩한다 (행별 최적 필터 + zlib 9).

```bash
python3 make-icons.py
```

앱 액센트(`#007aff`)에서 인디고로 흐르는 그라디언트 위에 바벨 마크를 얹는다.
`icon-192` · `icon-512` 는 모서리가 투명한 스퀘어클, `icon-512-maskable` 은
꽉 채우고 마크를 안전 영역(안쪽 80%) 안에 둔다. 셋 합쳐 76KB.

다크 모드는 킷이 다크 퍼스트라 값이 그대로 있다.
배경 `#060715`, 보더 흰색 10%, 콘텐츠 흰색 알파.

테마 선택은 `localStorage["gym.theme.v1"]` 에 저장하고,
`<head>` 의 인라인 스크립트가 **첫 페인트 전에** 적용해 화면이 번쩍이지 않게 한다.
`system` 이면 속성을 지워 `prefers-color-scheme` 에 맡긴다.

## 데이터

`localStorage` 키 세 개.

```
gym.logs.v1     { 종목ID: [ { date, sets:[{w,r,done}] } ] }
gym.custom.v1   { dayID: [ 추가한 종목 ] }
gym.theme.v1    "light" | "dark"   (system 이면 키 없음)
```

### 저장 시점과 날짜

**저장 버튼이 없다.** 칸에 값을 넣는 순간 들어간다.

```
세트 칸에 45 입력 → change
  → ensureEntry("d1-bench", "2026-08-10", 4)   ← 날짜 = 기록 날짜 선택값
  → saveLogs()
```

기록은 **종목이 바깥, 날짜가 안쪽**으로 쌓인다.
캘린더는 이걸 날짜 기준으로 뒤집어(`Gym.buildCalendar`) 그린다.
별도의 "운동 세션" 레코드는 없고, **그날 뭔가 입력했으면 그날 운동한 것**으로 본다.

값이 하나도 없는 세션은 저장하지 않는다. 카드를 펼치기만 해서는 아무것도 쌓이지 않는다.

중량 칸의 회색 숫자는 **placeholder 라 값이 아니다.**
그래서 횟수만 적으면 카드에 적힌 계획 중량을 실제 값으로 채워 넣는다.
입력창에도 그 숫자가 뜨니 다른 무게였으면 바로 고치면 된다.
맨몸 종목(계획 중량 0)은 채우지 않는다.

### 기록 날짜 바꾸기

운동 구획 상단 날짜 바에서 옮긴다. 헬스장에서 못 적었거나 자정을 넘겨 적을 때 쓴다.

```
‹  2026-08-07  ›            하루씩 이동 · 가운데를 누르면 달력에서 선택
07/15(수) · 26일 전에 기록 중   [오늘로]
```

오늘이 아니면 날짜 바가 경고색으로 바뀌고 헤더 날짜에도 표시가 붙는다.
**앞날에는 기록할 수 없다.**

캘린더에서 날짜를 누르고 "이 날짜에 기록하기" 를 눌러도 같은 곳으로 간다.

### 백업

브라우저 데이터를 지우면 기록도 사라진다. 설정 → 데이터 → 내보내기로 JSON 을 받아둔다.

```json
{
  "v": 1,
  "exportedAt": "2026-08-10T09:00:00.000Z",
  "logs": { "d1-bench": [ { "date": "2026-08-10", "sets": [ { "w": 45, "r": 8, "done": true } ] } ] },
  "custom": { "d1": [ { "id": "lib-bench", "name": "벤치프레스", "load": 40, "unit": "kg",
                        "sets": 4, "reps": "6-8회", "rest": 120, "cat": "chest" } ] }
}
```

**불러오기는 덮어쓰지 않고 합친다.** 같은 종목·같은 날짜만 파일 쪽 값으로 바뀐다.
들여온 값은 전부 검증·클램프를 거치니 손상된 파일을 넣어도 앱이 깨지지 않는다.

저장 공간이 가득 차면 조용히 넘어가지 않고 배너로 알린다.

## 종목 카탈로그

`exercises.js` 에 8개 부위 144종목.

```
가슴 20 · 등 22 · 어깨 17 · 이두 14 · 삼두 12 · 하체 27 · 코어 16 · 유산소·전신 16
```

검색은 세 가지로 걸린다.

```
벤치        이름 일부
ㅂㅊㅍㄹㅅ   초성 (부분 초성도 됨 — ㅅㅋㅌ → 스쿼트류)
deadlift    영문 별칭
```

같은 단어로 이어지는 쪽이 먼저 나온다. "벤치" 를 치면 `벤치프레스` 가 `벤치 딥스` 보다 위다.

카탈로그에서 고른 종목은 카탈로그 id(`lib-*`)를 그대로 쓴다.
그래서 같은 종목을 여러 요일에 넣어도 기록이 한 줄로 이어진다.
반대로 같은 날에 같은 이름을 두 번 넣는 건 막는다.

중량·세트·반복·휴식 기본값은 제안일 뿐이다. 등록할 때도, 등록한 뒤에도 고칠 수 있다.

## 설정

PWA 로 설치하면 브라우저의 캐시 삭제 메뉴가 묻혀서 찾기 어렵다. 그래서 앱 안에 뒀다.

| 항목 | 하는 일 |
|---|---|
| 화면 | 시스템 · 라이트 · 다크 |
| 업데이트 확인 | 서비스워커에 새 버전이 있는지 확인 |
| 캐시 비우고 새로고침 | 캐시 삭제 + 서비스워커 해제 + 새로고침 |
| 저장 공간 | 기록한 날·종목·세트 수, 기록 용량, 브라우저 할당량 |
| 데이터 | 백업 내보내기·불러오기·전체 삭제 |

**캐시 비우기는 앱 파일만 지운다. 운동 기록은 건드리지 않는다.**
기록까지 지우려면 데이터 → 전체 삭제.

현재 캐시 이름은 `caches.keys()` 로 직접 읽어 표시한다.
버전 문자열을 따로 두지 않으니 `sw.js` 의 `CACHE` 하나만 관리하면 된다.

## 배포

서비스워커는 **HTTPS 또는 localhost** 에서만 등록된다.
`file://` 로 열면 PWA 기능이 동작하지 않는다.

**GitHub Pages** — Settings → Pages → Source 를 `main` / `root` 로 지정
**Vercel** — `npx vercel --prod` (빌드 설정 없이 정적 파일 그대로)

### 설치

- **Android / Chrome** — 주소창 메뉴 → "앱 설치"
- **iOS / Safari** — 공유 → "홈 화면에 추가" (Chrome 아님, Safari 로 열어야 함)

### 캐시 갱신

`index.html` · `tokens.css` · `core.js` · `exercises.js` 를 수정하면
`sw.js` 의 `CACHE` 값을 올려야 확실히 반영된다.

```js
var CACHE = 'gym-v10';
```

서비스워커는 200 응답만 캐싱한다. 배포 중 404 나 502 가 떠도 캐시에 박히지 않는다.

## 알려진 제약

- **iOS 알림** — 홈 화면에 추가한 경우에만 가능. 현재는 비프음과 진동만 사용
- **폼 GIF** — 저작권 문제로 미포함. 유튜브 검색 링크로 대체
- **동기화 없음** — 기기 간 공유는 백업 파일 내보내기/불러오기로만
- **워밍업·어깨 서킷 ID 공유** — D01~D04 가 같은 종목 ID 를 쓴다.
  진행 기록이 한 줄로 이어지는 대신, 같은 날 두 세션을 하면 나중 것이 덮어쓴다
- **운동 소요 시간** — 세션 시작/종료 개념이 없어 기록하지 않는다

### 타이머

남은 초를 빼는 대신 **종료 시각을 잡아두고 매번 현재 시각과 비교**한다.
화면이 꺼져 틱이 누락돼도 돌아왔을 때 값이 맞다.
타이머가 도는 동안 Wake Lock 으로 화면을 켜두고, OS 가 잠금 중 회수하면 복귀 시 다시 잡는다.
(Wake Lock 은 iOS Safari 16.4 미만 미지원 — 이 경우 화면만 꺼지고 시간은 정확하다.)
